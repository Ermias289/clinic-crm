# True Care Dental and Implant Clinic Mobile App

A comprehensive Flutter mobile application for True Care Dental and Implant Clinic, providing patients with easy access to dental services, appointment booking, and clinic management features.

## 🏥 About Lib Dental and Implant Clinic

Lib Dental and Implant Clinic is dedicated to providing exceptional dental care with a focus on patient comfort and advanced dental technology.

## 🎨 Brand Colors

- **Primary Navy Blue**: #1F3A5F
- **Accent Mint Green**: #7CB342

## 📱 App Features

- Patient appointment booking
- Service catalog browsing
- Payment processing
- Profile management
- Notifications
- Dental card management

## 🚀 Getting Started

### Prerequisites
- Flutter SDK (latest stable version)
- Android Studio / VS Code
- iOS development tools (for iOS builds)

### Installation

1. Clone the repository
```bash
git clone <repository-url>
cd mobile-app
```

2. Switch to True Care branch
```bash
git checkout company/TrueCareDentalClinic
```

3. Install dependencies
```bash
flutter pub get
```

4. Run the app
```bash
flutter run
```

## 📦 Build Configuration

- **Package Name**: `com.truecaredentalclinic.app`
- **App Name**: True Care Dental and Implant Clinic
- **Target Platforms**: Android, iOS

## 🏗️ Architecture

The app follows Clean Architecture principles with:
- **Presentation Layer**: UI components and controllers
- **Domain Layer**: Business logic and entities
- **Data Layer**: Repositories and data sources

## 🎯 Development

This app is built using:
- Flutter framework
- GetX for state management
- Clean Architecture pattern
- RESTful API integration
